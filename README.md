## → About

Full stack AI engineer currently building an AI-powered **OSINT intelligence platform** for the Government of Pakistan — large-scale web scraping, RAG-based knowledge retrieval, fine-tuned LLMs for classification and entity extraction, and surface/deep/dark-web monitoring, wired together with n8n and served through React + FastAPI. Before that: agentic AI systems, predictive analytics pipelines, and a mental-health chatbot (MindGuard) built on LangChain and vector search.
