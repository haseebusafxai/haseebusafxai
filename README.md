## → About

Full stack AI engineer currently building an AI-powered **OSINT and dark-web intelligence platform** for the Government of Pakistan — large-scale web scraping, RAG-based knowledge retrieval, fine-tuned LLMs for classification and entity extraction, and surface/deep/dark-web monitoring, wired together with n8n and served through React + FastAPI. Alongside that, I build **agentic AI systems**, **automation pipelines** (lead-gen agents, content/YouTube agents), and **air-gapped AI deployments** for secure environments.
